# Revision 2026-09-30 (published 2026-10-01)

This release provides the corrected code and aggregate results corresponding to the revised manuscript. The previous submission remains accessible by its original commit; no history was rewritten.

## Analysis corrections

- SICdb hourly vital summaries enter only once the source hour is complete.
- Accepted measurement ranges are applied before study-level summaries and latest-valid-value selection; MIMIC and SICdb inputs were regenerated and the fixed candidate models refitted in MIMIC.
- The executable eICU query retains unitdischargeoffset. Events require initiation strictly after the prediction landmark, before six hours and before unit exit.
- An emitted alert counts as correct only within its own prediction window. Early false alerts can suppress later opportunities. Clinical detection uses event-positive stays and reports false-alert burden separately.
- Held-out Brier reference probabilities come from the calibration subset. Full-cohort prevalence references are separately descriptive.
- Model differences have paired stay-bootstrap intervals. Repeated splits and bootstrap sampling use revision seed 20260930; HGB retains seed 20260823.
- All current-cohort QC, subgroup and first-agent summaries were regenerated. Supplementary results include measurement-age sensitivities, exit composition, source-rejection counts and admission-period audits.

## Interpretation and validation

MIMIC groups reflect patient reference periods; they do not establish strict admission chronology. Prior exposure to external results cannot be reconstructed and is not removed by the revised analysis. Source-hour aggregates and database creators' upstream processing also limit retrospective audits.

The release uses verified existing aggregate outputs. Publication checks cover manifest hashes, Python syntax, sensitive-file screening, unchanged result/SQL hashes and the existing alert-logic tests. The portable package was not independently rerun end to end on all three databases for publication.
